# D2 Measurement and Testing Outputs

This directory stores measurement reports and testing outputs for SOEN 6611 Deliverable 2.

- `SLOC/`: Physical and Logical SLOC counting results, counting schemes, and supporting calculations (Problem 5).
- `Readability/`: Source-code readability measurement results, metric references, and threshold interpretation (Problem 6).
- `TestResults/`: Representative test datasets, execution results, and evidence for Problem 4(b).

Production Java source code remains under `Source/`. Test source code must be excluded from the production SLOC counts.

Generated reports should identify the source-code version or Git commit used for measurement.
